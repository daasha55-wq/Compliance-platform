# Конкурентный анализ: Compliance-платформа для финтех-стартапов

Дата подготовки: 2026-08-20

## Выбор конкурентов и обоснование

Из списка кандидатов (Sumsub, Alloy, ComplyAdvantage, Onfido/Entrust, Persona, Trulioo, Unit21, ComplyCube, Veriff) для анализа отобраны 5 продуктов, наиболее релевантных именно для целевой аудитории брифа — растущих финтех-стартапов с CPO и compliance-офицером в роли покупателя, а не крупного enterprise/банковского сегмента:

1. **Sumsub** — самый узнаваемый all-in-one KYC/KYB/KYT/AML игрок именно в сегменте финтех- и крипто-стартапов; максимально близок по позиционированию "всё в одной подписке" к нашему продукту. Также интересен тем, что в брифе именно Sumsub указан как вендор-источник данных — полезно понять, где он сам превращается в конкурента "оркестрации".
2. **Alloy** — специализируется именно на orchestration-слое поверх десятков identity/fraud/AML/credit-источников для банков и финтехов; архитектурно ближайший аналог нашей модели (мы тоже оркестрируем Sumsub + ComplyAdvantage + собственный скоринг).
3. **ComplyAdvantage** — эталон в сегменте sanctions/PEP/AML-скрининга, второй прямой вендор из брифа; в 2025-2026 эволюционировал в платформу Mesh с полноценным кейс-менеджментом и explainable AI — прямой конкурент по риск-скорингу и explainability.
4. **Persona** — лидер по UX/developer experience среди identity-платформ, наиболее популярен именно у growing-стартапов (в т.ч. YC-компаний) благодаря self-serve входу и free tier — важный бенчмарк UX-планки для нашей аудитории.
5. **Unit21** — специализируется на кейс-менеджменте и investigation-workflow для AML/fraud, включая AI-нарративы решений и guardrails "когда нужен human review" — концептуально ближе всех к connectу explainability + 4-eyes из брифа.

Исключены: **Onfido/Entrust** — после поглощения Entrust сместился в сторону enterprise/gov-identity, менее ориентирован на self-serve для стартапов; **Trulioo** — прежде всего сеть провайдеров идентификации/глобальное покрытие, слабее дифференцирован по кейс-менеджменту и explainability, которые ключевые для нашего брифа; **Veriff** — по функциональности близок к Sumsub/Persona, но заметно меньше материала по AML/PEP-глубине и кейс-менеджменту; **ComplyCube** — меньший игрок, менее подходит как ориентир для бенчмарка.

## Выводы по каждому конкуренту

**Sumsub.** Сильнейший all-in-one бренд в KYC/AML для финтех- и крипто-стартапов, максимально близкий по позиционированию к нашему продукту — но именно поэтому он одновременно и вендор "под капотом" (по брифу), и потенциальный прямой конкурент, если решит развивать оркестрацию сторонних AML-источников глубже. Его слабое место для нашей ниши — цена ощущается высокой для самых маленьких команд (минимум $299/мес на Compliance-плане) и enterprise-темп внедрения несмотря на формально self-serve триал. Это оставляет пространство для продукта, явно оптимизированного под growing-stage, а не "уже достаточно крупных, чтобы позволить себе Sumsub".

**Alloy.** Ближайший архитектурный аналог нашего продукта: оркестрация поверх множества identity/fraud/compliance-источников — концептуально то же самое, что мы делаем поверх Sumsub + ComplyAdvantage + собственного скоринга. Но Alloy — тяжёлый enterprise-sales продукт (обязательный Solutions Engineer, демо, pilot pricing, непубличная цена), что делает его малодоступным для growing-стартапов на ранних стадиях без выделенного бюджета и dev-ресурса — прямая точка дифференциации для нас через доступность входа.

**ComplyAdvantage (Mesh).** Сильнее всех в части regulatory-grade explainability (явное позиционирование под EU AI Act/DORA) и имеет реальную программу для ранних стартапов (ComplyLaunch), что делает вход по цене привлекательным. Но повторяющаяся в отзывах боль — высокий false positive rate и "неполноценный" UI кейс-менеджмента — прямое совпадение с false positive rate как ключевой OKR-метрикой нашего брифа, то есть это именно та проблема, на решении которой явно строится наш продукт.

**Persona.** Безусловный лидер по UX/DX среди всей пятёрки — щедрый free tier (500 верификаций/мес), self-serve вход, понятная документация, топ рейтинги на G2. Но фокус продукта остаётся преимущественно на identity verification (KYC/KYB) без такой же глубины AML/sanctions/transaction-monitoring кейс-менеджмента — то есть Persona закрывает лишь часть стека, который наш продукт объединяет в одной подписке.

**Unit21.** Концептуально ближе всех к паттернам explainability + guardrails из брифа — AI генерирует нарратив решения, но система явно помечает, когда обязателен human review, что перекликается с идеей 4-eyes. При этом продукт полностью sales-led, без публичной цены и self-serve входа, и ориентирован на компании с уже зрелой compliance-функцией и объёмом кейсов, а не на растущие стартапы, только выстраивающие процесс с нуля.

## Общие выводы для нашего продукта

**Где ниша.** Ни один из пяти конкурентов не закрывает одновременно все три вещи: (а) доступный self-serve вход именно для growing-стартапов, (б) полный стек KYC + AML + sanctions/PEP + GDPR/PDPA-контекст в одной подписке, и (в) UX кейс-менеджмента, спроектированный явно вокруг риск-тиров и объяснимости. Persona ближе всех по UX и порогу входа, но узка по AML/sanctions-глубине. Sumsub близок по широте стека, но дорог и медленно внедряется для самых ранних клиентов. Alloy и Unit21 архитектурно и по explainability-философии ближе всего к нашей модели, но оба — чисто enterprise sales-led продукты без прозрачной цены, недоступные стартапу, который хочет попробовать продукт без цикла из демо и pilot pricing. Это и есть ниша: "Alloy/Unit21-уровня оркестрация и explainability, но с Persona-уровня доступностью входа для команды из 20-200 человек".

**Где наш продукт может быть сильнее (используя дифференциаторы из брифа):**
- *Матрица эскалации по риск-тирам (Low/Medium/High)* как явный, видимый пользователю UI-паттерн — ни один конкурент не выставляет напоказ модель "кто решает и по какому механизму" (auto-approve / soft-block SLA / жёсткое вето); у всех пятерых это скрыто внутри no-code rules/decision engine как настройка, а не как понятный workflow-язык для CPO и compliance одновременно.
- *4-eyes подтверждение* с отдельной ролью Senior Compliance Officer и явным статусом кейса "Ожидает подтверждения" — у Unit21 есть похожая идея guardrails "когда нужен review", но не оформленная как отдельный workflow-статус с отдельной ролью и точкой в аудит-следе. Формализация этого как первоклассного состояния кейса — реальное отличие.
- *Explainability прямо в карточке кейса* (progressive disclosure, а не отдельный отчёт) — ComplyAdvantage и Unit21 продвинуты в explainability "под капотом" (regulatory alignment, AI-нарративы), но именно у ComplyAdvantage отзывы жалуются на неполноценный UI кейс-менеджмента. Встроить explainability-блок (версия модели + входные данные) прямо в основной экран разбора кейса, а не прятать за отчётом, — сильная точка отличия.
- *Явный показ расхождения источников* (Sumsub 80% совпадение / ComplyAdvantage ничего не находит, вместо усреднённого скора) — ни один из конкурентов не позиционирует это как отдельный, читаемый UI-элемент; для orchestration-продукта поверх нескольких вендоров это прямое конкурентное преимущество в доверии compliance-офицера к системе.

**UX-паттерны конкурентов, которые стоит перенять:**
- No-code workflow/flow-builder на визуальном канвасе (Sumsub Workflow Builder, Persona Flow Editor, Alloy decision engine) — хороший, проверенный паттерн для настройки риск-правил без участия разработчиков; подходит для конфигурации риск-тирной матрицы под юрисдикцию в будущем (архитектурно заложено в брифе вне MVP-скоупа).
- Программа доступного входа для ранней стадии (ComplyAdvantage ComplyLaunch, Persona free tier 500 верификаций/мес) — снижает порог пробы продукта для самых маленьких команд, соответствует seats+usage-overage модели монетизации из брифа как естественная точка входа "бесплатно до X кейсов/мес".
- AI-нарратив "черновик решения, готовый к review" (Unit21) — сильный паттерн для explainability-блока: не просто показывать цифры скоринга, а формулировать причину вердикта человеческим языком, который compliance-офицер может отредактировать/подтвердить — снижает когнитивную нагрузку при разборе High-risk кейсов.
- Богатая аналитика по кейсам/очередям (40+ дашбордов у Unit21) — полезный ориентир для вторичного экрана CPO (onboarding conversion, override rate по типам флага, time-to-decision по тирам) из метрик брифа.
