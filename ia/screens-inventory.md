# Инвентаризация экранов

Источник: `prd_extended.md` (разделы 5, 7, 8, 10, 11, 17 — MVP-экраны, роадмап v1.1/v2.0, RBAC).

## Экраны и состояния, упомянутые в PRD

| Имя | Что на нём происходит |
|---|---|
| Login | Вход, определение роли (Compliance Officer / Senior Compliance Officer / CPO) |
| CaseQueue | Очередь кейсов — обзор и приоритизация того, что требует внимания |
| CaseDetail | Карточка кейса — прогрессивное раскрытие: сводка → детали (документы, история, расхождение источников) → решение |
| ConfirmationQueue | Очередь кейсов в статусе «Ожидает подтверждения» — видна только Senior Compliance Officer |
| CaseHistory | Read-only вкладка аудит-лога внутри карточки кейса (кто/когда/что + версия модели) |
| CPODashboard | Дашборд CPO — override rate, onboarding conversion, прогноз счёта (v1.1) |
| RiskRuleBuilder | No-code конструктор риск-правил — настройка матрицы риск-тиров (v1.1, фича #31) |
| CaseImportWizard | Read-only импорт исторических кейсов при миграции с прежнего вендора (v2.0, фича #30) |
| DemoDashboard | Демо-дашборд с примерными цифрами до контакта с sales (Won't have now, фича #35 — зависит от нерешённого GTM-вопроса) |
| SignupPricing | Self-serve регистрация / страница цены (Won't have now, фича #34 — зависит от нерешённого GTM-вопроса) |

## Экраны, которых нет в PRD, но без которых продукт не соберётся

| Имя | Что на нём происходит |
|---|---|
| NotFound | 404 — переход по несуществующей/удалённой ссылке на кейс |
| EmptyCaseQueue | Очередь пуста — нет кейсов, требующих внимания прямо сейчас |
| ErrorState | Внешний источник (Sumsub/ComplyAdvantage) недоступен или вернул ошибку — состояние карточки кейса |
| LoadingState | Загрузка данных кейса/очереди |
| Onboarding | Первый вход в аккаунт: начальная настройка, приглашение команды |
| AccountSettings | Базовые настройки — профиль, уведомления |
| TeamManagement | Назначение ролей пользователям (Compliance Officer / Senior CO / CPO) — необходимо, т.к. в PRD есть RBAC с 4 ролями (раздел 11), но нет экрана их назначения |

## Открытый вопрос

DemoDashboard и SignupPricing существуют в PRD только как «Won't have (now)», обусловленные нерешённым GTM-вопросом (self-serve vs sales-led). Включаю их в инвентарь, потому что они упомянуты в документе, но их итоговая судьба в sitemap зависит от бизнес-решения, которое ещё не принято.
