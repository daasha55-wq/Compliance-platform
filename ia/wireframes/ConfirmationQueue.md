# ConfirmationQueue

**Размер:** desktop 1440×1024
**Назначение:** Senior Compliance Officer видит кейсы, эскалированные через формальный 4-eyes, и выносит финальное защитимое решение (PRD, раздел 6, user story 7)

## Секции (сверху вниз)

### Header (64px высота)
- Logo (левый край)
- Заголовок раздела: «Ожидает подтверждения»
- Avatar + меню профиля (правый край) — роль «Senior Compliance Officer» подписана рядом с именем

### Sidebar (240px ширина, слева)
- Confirmations (active)
- Account Settings

### FilterBar (48px высота, под header, над таблицей)
- Сегмент-контрол по риск-тиру: Все / Medium / High
- Сортировка: по дате эскалации / по риск-тиру
- Счётчик справа: «5 кейсов ожидают подтверждения»

### ConfirmationTable (основной контент, растягивается по высоте)
Колонки слева направо:
- **Риск-тир** — иконка формы + подпись (▲ High / ◆ Medium), тир обозначен формой, не только цветом
- **Заявитель** — имя
- **Эскалировал** — имя Compliance Officer, направившего кейс на подтверждение
- **Заметка эскалации** — короткая цитата из обоснования офицера (обрезана до одной строки, полный текст — в CaseDetail при открытии), см. user story 7 AC про полный контекст с заметкой первого офицера
- **Дата эскалации**
- **В ожидании** — сколько времени кейс уже висит в очереди («6ч», «1д 4ч»)
