# CaseQueueEmpty

**Размер:** desktop 1440×1024
**Назначение:** очередь кейсов, в которой нет ни одного кейса, требующего внимания — главный рабочий экран Compliance Officer без данных. Уже существовал как скрытое `EmptyState` внутри `CaseQueue.CaseTable`; этот файл — тот же контент, вынесенный в отдельный видимый экран (по аналогии с `CaseDetailRejected`).

## Секции (сверху вниз)

### Header (64px высота) — идентично CaseQueue
- Logo + заголовок «Очередь кейсов»
- Avatar (правый край)

### Sidebar (240px ширина, слева) — идентично CaseQueue
- Case Queue (активный)
- Account Settings

### Main (FILL×HUG)

#### FilterBar — идентично CaseQueue
- Тир / Статус / Сортировка — те же контролы, что и на заполненной очереди (фильтры остаются доступны даже когда результат пуст)
- Справа: «0 кейсов в очереди»

#### EmptyPlate (по центру оставшегося пространства)
- Плейсхолдер-иллюстрация 120×120 (`surface-subtle`)
- Заголовок «Очередь пуста» (`DS/Heading/lg`)
- Подпись «Новые кейсы появятся здесь по мере поступления заявок» (`DS/Body/sm`, `text-muted`)
- Без CTA — очередь наполняется системой автоматически, действие пользователя не требуется (решение уже зафиксировано в `ia/wireframes/CaseQueue.md`)
