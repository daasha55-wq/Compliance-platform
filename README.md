# Compliance-платформа для финтех-стартапов

React-база проекта: приложение и UI-кит (компоненты, токены дизайн-системы, foundation).

## Из чего состоит

- `src/` — React-приложение и UI-кит (компоненты, токены дизайн-системы, foundation)
- `public/` — статические ассеты
- Конфиги: `package.json`, `vite.config.ts`, `tsconfig*.json`, `.oxlintrc.json`

## Как запустить

```bash
npm install
npm run dev      # React-приложение (Vite)
npm run build    # production-сборка
```

## Стек

React 19, Vite, TypeScript, CSS Modules.
